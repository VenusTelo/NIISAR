1. HOW TO INSTALL AND RUN THE APP
--------------------------------------------------------------------------------
This project runs on Python 3.9+ (Windows, macOS, or Linux) and connects 
directly to NASA Earthdata and the Alaska Satellite Facility (ASF).

Step 1: Open a terminal inside the project directory (where app.py is located).

Step 2: Create a virtual environment and install the required packages:

   python -m venv .venv

   # Activate the environment:
   # On Windows (PowerShell):
   .\.venv\Scripts\Activate.ps1
   # On macOS / Linux:
   source .venv/bin/activate

   # Install dependencies:
   pip install streamlit asf_search earthaccess h5py numpy pandas pydeck altair

Step 3: Launch the Streamlit server:

   streamlit run app.py

Step 4: Open http://localhost:8501 in your browser (it usually opens on its 
own). Press Ctrl + C in the terminal when you want to stop the server.


2. SYSTEM ARCHITECTURE & DESIGN CHOICES
--------------------------------------------------------------------------------
NISAR Monitor is a self-contained Python application (app.py) built for the 
NASA Space Apps Challenge ("Dancing with the SARs") to bridge the gap between 
raw L-band SAR granules and actionable environmental insights.

Core Stack:
- Streamlit: Web interface, reactive sidebar state, and dual-mode layout.
- asf_search: Queries the ASF catalog by point geometry, processing level, 
  relative orbit (Track), and Frame.
- earthaccess & h5py: Handles NASA Earthdata URS authentication and streams 
  remote HDF5 (.h5) datasets over HTTP without full granule downloads.
- NumPy & Pandas: Array subsetting, linear-to-decibel ($dB$) conversion, 
  interferometric displacement math, and summary tables.
- PyDeck & Altair: Renders georeferenced raster polygons over Carto basemaps 
  and generates before/after statistical distributions.

Key Engineering Highlights:
- Cloud Subsetting (No Multi-GB Downloads): Raw NISAR HDF5 files are large. 
  The reader inspects `/science/LSAR` coordinate vectors (`xCoordinates`, 
  `yCoordinates`) first and slices only the exact bounding window requested 
  by the user's zoom slider.
- Zero-GDAL Map Projections: Forward and inverse coordinate math for WGS84 
  ($EPSG:4326$), UTM zones ($EPSG:326XX$ / $327XX$), and EASE-Grid 2.0 
  ($EPSG:6933$ for L3 soil moisture) are implemented in pure Python so any 
  evaluator can run the code out of the box without binary GIS conflicts.
- Automated Multi-Date Alignment: When comparing two dates, the code crops 
  both matrices to their shared spatial intersection and aligns pixels before 
  computing deltas, handling resolution differences (such as `frequencyA` vs. 
  `frequencyB` on GCOV).


3. TESTING WORKFLOW (5-MINUTE WALKTHROUGH)
--------------------------------------------------------------------------------
1. Authenticate:
   In the left sidebar under "1. NASA Earthdata Account", enter a valid NASA 
   Earthdata Username (not email) and Password.

2. Pick a Study Area & Scale:
   - Use one of the pre-configured Honduras presets ("Gracias a Dios / Caratasca 
     Lagoon" or "Roatán / Bay Islands") or enter any global Latitude/Longitude.
   - Keep "Measurement area" between 30 km and 80 km for fast cloud streaming 
     (250 km loads the full granule).
   - Set Track = 0 and Frame = 0 if you want to list every available orbital 
     pass over custom coordinates.

3. Select a NISAR Product Level:
   - GCOV (Level 2): Geocoded backscatter ($dB$) for open water, flooding, 
     forest cover ($km^2$, $ha$), and Radar Vegetation Index ($RVI$).
   - GUNW (Level 2): Unwrapped interferometric phase ($rad$) converted to 
     Line-of-Sight displacement ($cm$), velocity ($mm/yr$), and coherence.
   - SME2 (Level 3): Volumetric soil moisture ($m^3/m^3$ and $\%$), saturation 
     area ($> 0.40\ m^3/m^3$), and spatial correlation ($r$).
   - GSLC / RSLC (Level 2 / Level 1): Full-resolution complex amplitude ($dB$). 
     Keep the measurement area under 20 km when testing SLC products.

4. Compare Two Dates:
   Choose "Date 1 (Before)" and "Date 2 (After)" at the top. Matching the same 
   Track and flight direction (Ascending/Descending) gives the cleanest result; 
   if they differ, the app warns you and restricts calculations to the overlap.

5. Toggle Between User Modes:
   - Intuitive Mode: Built for non-specialists and local decision-makers, 
     featuring plain-language "(i)" tooltips on every metric row.
   - Scientific Mode: Exposes calibrated color bars, physical interpretation 
     ranges, standard deviations, and a live HDF5 (.h5) internal dataset and 
     metadata browser next to the map.
